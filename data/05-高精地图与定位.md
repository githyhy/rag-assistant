# 高精地图与定位

## 一、高精地图与普通导航地图的区别

| 维度 | 普通导航地图 | 高精地图 |
|------|------------|---------|
| 精度 | 米级 | **厘米级** |
| 服务对象 | 人 | 机器（自动驾驶系统） |
| 内容 | 道路拓扑、POI | 车道级几何 + 语义属性 |
| 更新频率 | 季度/月度 | 天级甚至小时级 |
| 数据量 | 小 | 极大（每公里 GB 级） |

**一句话区别**：导航地图告诉你"走哪条路"，高精地图告诉车辆"走哪条车道、线在哪、限速多少、坡度多大"。

## 二、高精地图包含什么

### 1. 几何信息

- 车道中心线与车道边界线（实线、虚线、双线）
- 道路曲率、坡度、横坡
- 路口形状、导流线

### 2. 语义信息

- 车道数量、车道类型（直行/左转/右转/公交专用）
- 限速值
- 交通标志与红绿灯位置
- 人行横道、停止线
- 减速带、隧道、桥梁

### 3. 定位特征层

- 路面特征点
- 杆状物、建筑轮廓
- 用于车辆匹配定位的稳定特征

## 三、定位技术

自动驾驶需要知道**自己在哪、朝向哪、有多快**，精度要求厘米级。

### 1. GNSS 卫星定位

- 原理：接收多颗卫星信号，通过三角测量解算位置
- 单独使用精度：**米级**，不够用
- 问题：城市峡谷、隧道、地下车库中信号丢失或多径反射

### 2. RTK 实时动态差分

- 原理：通过基准站播发差分改正数，消除大部分误差
- 精度：**厘米级**
- 问题：依赖差分服务覆盖与通信链路，遮挡环境下仍会失锁

### 3. IMU 惯性测量单元

- 原理：陀螺仪测角速度，加速度计测加速度，积分得到位姿
- 优点：**不依赖外部信号**，短时精度高，更新频率高
- 缺点：**误差随时间累积**（漂移），必须与其他传感器组合

### 4. 轮速计

- 测量车轮转动，推算行驶距离与速度
- 优点：成本低、可靠
- 缺点：打滑时误差大

### 5. SLAM 同步定位与建图

- 原理：一边建图一边定位，用观测到的环境特征反推自身位置
- **激光 SLAM**：用点云与地图匹配，精度高，不受光照影响
- **视觉 SLAM**：用图像特征点，成本低，但受光照与纹理影响
- 问题：环境变化（施工、积雪）会导致匹配失败

## 四、多传感器融合定位

实际系统通常采用**组合定位**方案：

```
GNSS + RTK  →  提供绝对位置（低频、可能有跳变）
IMU         →  提供高频姿态与加速度（短时准，长期漂移）
轮速计      →  提供里程增量
激光/视觉   →  与高精地图匹配，修正累积误差
         ↓
    卡尔曼滤波 / 因子图优化
         ↓
      高频、厘米级、连续的位姿输出
```

**核心思想**：用不同传感器的**误差特性互补**——
绝对定位修正漂移，惯性测量填补信号丢失的间隙。

## 五、高精地图的争议与趋势

### 争议

- **成本高**：采集与更新需要专业车队，覆盖全国代价极大
- **鲜度难保证**：道路天天在变，地图更新跟不上
- **政策限制**：测绘资质与数据合规要求严格

### 趋势

1. **轻地图 / 无图方案**：只保留必要的导航信息，靠车端感知实时理解道路。
2. **众包更新**：用车队回传数据自动发现道路变化。
3. **记忆地图**：车辆自己跑过一遍后记住路线，用于固定通勤场景。
4. **BEV + 地图融合**：把实时感知结果与地图先验结合，互为补充。

行业共识是：**地图仍然有价值，但不再是"必须提前建好"的强依赖**。
